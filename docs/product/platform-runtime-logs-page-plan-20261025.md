# 运行日志页面与验收方案

状态：DESIGN ONLY，2026-10-25。目标是让有资格的空间运维人员查找运行记录、查看一条记录并返回原位置。本轮交付文字流程稿，不开发页面、API、采集器或新样例，不更新运行中的新版预览。技术字段、资格和来源规则只由[运行日志只读契约](../architecture/platform-runtime-logs-readonly-v1.md)拥有，本文不另立接口规则。

真实来源仍UNCONFIGURED，日志读取资格和拟议API未实现；现有管理页面及OIDC/RP、原库、Agent API保持。PR #363保持Draft，不合并、不部署；业务写入口、模型、真实执行继续关闭。

## 1. 页面职责和复用

保留系统设置左侧现有“运行日志”菜单，不在顶部再加入口、不增加总览仪表盘。沿用新版设置壳的当前空间条、标题、筛选、表格、独立详情和折叠依据；视觉参考为已交付的[基础配置页面](platform-management-configuration-readonly-20261025/configuration.png)，不另选风格或重做整个设置。

直接复用现有管理查询的完整GET重验、错误/未接入状态、筛选后回首页、详情返回和原行定位流程；数据适配来自未来日志Reader，不复用AuditEvent或执行列表充数。需适配的是时间窗口、固定服务/级别、受保护cursor、稳定rowKey和明确entryRef。没有可退休的生产日志页或采集器；原hash路由样例仅保留历史演示，不迁移为可信来源。

| 区域 | 主要内容 | 信息层级 |
|---|---|---|
| 当前空间条 | 当前已核验工作空间、切换与核验身份 | 直接沿用；空间配置名称不授予访问资格 |
| 标题 | 运行日志；“查看当前空间的服务运行记录” | 一个标题、一句说明；不加领导演示、Core、fixture或健康总分 |
| 状态区 | 未配置、无权限或来源异常时的唯一主状态 | 正常查询不重复展示多条边界说明 |
| 查询区 | 记录时间、服务、级别、查询、清除条件 | 唯一主操作“查询”；无任意正文搜索/原生语法输入 |
| 结果区 | 记录时间、级别、服务、摘要、查看记录 | 不显示原生ID、主机、URL、stack和自由正文 |
| 页尾 | 本次窗口、返回查询首页、更早记录 | 不显示未经证实的总数或“第N/M页” |
| 折叠依据 | 查询时点、时间依据、范围引用、只读说明 | 普通查看时收起；不重复API/模型/权限技术名词 |

## 2. 页面和具体流程

### 2.1 未接入状态

当前`/settings/logs`保留原未接入行为。本稿未来文案为标题“运行日志尚未接入”，正文“尚未配置当前空间的运行日志来源”，仅提供“返回设置总览”。不渲染空表、0条记录、虚构错误、示例服务或查询成功状态，不因没有来源向用户要求重新登录。

无额外日志资格与来源未配置分别处理；未来若来源已配置而记录读取返回403，展示“没有当前空间的运行日志查看权限”，不将它翻译成未配置或0条。原无账号预览不增加真实登录入口。

### 2.2 查询列表

未来页面仍用`/settings/logs`。来源满足契约后，首次查询默认最近1小时，由Web服务端规范成明确UTC起止时间；URL保留固定窗口。筛选展示“记录时间”，并在折叠依据解释它是来源观察时间，避免把缺失发生时间补成真实发生时刻。

服务选项为“全部服务、应用服务、后台处理”；级别为“全部级别、常规、注意、异常、严重异常、未分类”。这些是固定业务名称，不能用来源返回的服务名或severity原文填下拉框。时间控件可提供最近1小时/今天/自定义，提交前一律变为契约内的明确窗口；“今天”超预算时给出时间错误，不静默扩大范围。

查询后显示最多25条当前可见记录，固定从新到旧；“更早记录”只在有下一位置时可用。改筛选或时间后回查询首页并丢弃旧cursor/详情；清除条件由用户显式重置为新的最近1小时。普通刷新保留原起止时间，不偷偷更新窗口。V1不显示总量、趋势、成功率、健康判断、全文搜索、导出、下载、实时tail、自动轮询、复制原文或重试任务。

### 2.3 记录详情

点击“查看记录”进入同一固定页面的独立详情状态，URL携带entryRef并保留原窗口、服务、级别、cursor及稳定行定位引用。详情标题“运行记录详情”，页面仅展示一条记录：记录时间、发生时间（缺失显示“未提供”）、级别、服务、固定业务摘要。“查看查询依据”折叠展示最小范围引用与查询时点。

不在列表下再堆详情，不提供“重新执行、修复、清理、删除、切换日志级别、下载原文”等动作；不生成未接入的追踪或业务对象链接。返回按钮固定“返回运行日志”，剥离entryRef，恢复原窗口/筛选/cursor并定位原rowKey。entryRef续期变化不能让DOM行引用跟着变化。

原记录已不可见时只给明确错误和返回原列表。返回后原行因保留期/来源变化不在可见结果中，提示“原记录当前不可见”，保留查询条件；不得选第一条或最新记录代替。位置过期时显示“查询位置已失效”，由用户点击“按当前条件重新查询”，显式回首页。

### 2.4 空间、刷新、历史与返回设置

所有入口沿用现有身份核验和完整GET。切换空间经既有`/identity`重验，重新进入新空间的日志来源状态；不自动把旧cursor、entryRef或查询结果带到新空间，也不能靠相同人员名字放行。复制旧空间详情到新空间返回不可见/拒绝，返回时显示新空间状态。

未来可接受唯一导航来源`from=configuration`，它只用于固定返回基础配置，不传到API、不选择身份或空间、不接受任意return URL。现有基础配置DTO仍是原六项查询，不在本设计里加logs键或伪造已接入链接；未来需要同时修改前后端严格验证并另行验收，不能先开放客户端入口。

详情刷新读取同一精确记录；列表刷新重查同一条件和位置。前进/后退、撤权、到期后不能从缓存展示成当前成功结果。无权限或来源错误不保留敏感旧记录；合法筛选可保留以便重验，token、原生参数和日志内容不得进入浏览器存储或任意返回地址。

### 2.5 窄屏与可访问性

沿用现有390px布局：筛选纵向排列，查询和返回完整可见；表格只在容器内部横向滚动，不撑宽整页。独立详情避免长正文或ID压坏布局。输入具有明确标签与关联错误，键盘能依次到达查询、记录、返回；返回原行使用稳定rowKey并恢复焦点。错误作为当前区域状态宣读，不靠红绿颜色区分级别。

## 3. 状态文案

| 状态 | 主文案 | 允许动作 |
|---|---|---|
| 未配置 | 运行日志尚未接入 | 返回设置总览 |
| 来源无法满足安全查询 | 来源暂不支持当前查询 | 返回设置；不展示技术配置细节 |
| 加载 | 正在查询运行记录 | 不展示旧记录为新结果；不自动重复查询 |
| 成功有记录 | 按表格呈现，无额外成功横幅 | 查看记录、更早记录、返回查询首页 |
| 成功无匹配 | 当前条件下没有运行记录 | 调整条件；不显示系统运行正常 |
| 来源异常 | 运行记录暂时无法读取 | 手动重新查询，保留合法条件 |
| 登录失效/撤权 | 登录状态不可用 / 没有当前空间的运行日志查看权限 | 重新核验身份 / 返回设置 |
| 引用或时间窗失效 | 查询位置已失效 / 当前时间范围已不可查询 | 显式重查首页 / 修改时间 |
| 精确详情不可见 | 指定运行记录当前不可见 | 返回原列表，不补最新记录 |

这些是待实现文案，不是已更新截图或已通过浏览器验收的界面。

## 4. 异常验收矩阵

以下均为未来EXPECTED规格，本轮NOT_RUN；纸面核对只证明设计覆盖，不替代Adapter、PG或浏览器测试。未来先在独立合成环境完成，再按另行授权做真实来源见证。

| 编号 | 输入或异常 | 必需结果 |
|---|---|---|
| RL01 | 无来源、缺来源绑定、目录已配但日志未配 | 未接入；不请求日志，不显示0或目录/审计样例 |
| RL02 | 仅管理读、仅日志读、普通验收读或无workspace grant | 列表/详情拒绝；来源状态仍按其独立资格处理，不默认授予新能力 |
| RL03 | A空间复制B的cursor/entryRef、伪造tenant/URL/header | 查询拒绝且无B记录/是否存在信息；不能前端过滤后成功 |
| RL04 | 读取中令牌、actor、binding、grant或任一能力撤销/到期 | 整次结果丢弃；前进/后退/刷新不复活；恢复资格也不复活旧revision |
| RL05 | 原生来源权限撤销、绑定或投影版本切换 | 不返回旧结果；版本引用失效需显式重新查询 |
| RL06 | 同纳秒26条以上、同正文多次发生、跨服务同时间 | 稳定occurrence排序，不能减时间漏读或hash合并；不满足则不准入 |
| RL07 | 重复/乱序/错空间/缺时间/截断/超量/超预算页 | 整页不可用，无部分成功；未知合法级别只显示未分类 |
| RL08 | body/stack/SQL/URL/PII/credential及带secret的异常响应 | Web JSON、SSR/RSC、DOM、URL、存储、截图、错误均无这些内容；固定摘要替代原文 |
| RL09 | 第二页→详情→刷新→返回原页原行 | 相同窗口/筛选/cursor、精确记录与rowKey；不回首页或更换记录 |
| RL10 | 改时间/服务/级别、清除条件、普通刷新 | 改条件清旧位置；清除显式重置；刷新保持原固定时间窗 |
| RL11 | cursor/entryRef到期、篡改、不同caller、绑定/密钥轮转 | 明确位置失效或拒绝，无静默新查询；只经当前身份重查 |
| RL12 | 记录过期/删除、同ID投影变化、无匹配、来源异常、保留时间窗失效 | 各状态分开；同ID变化拒绝旧详情，无匹配不证明健康，不以最新记录补历史 |
| RL13 | 切空间与复制旧详情后返回 | 新空间状态，无原空间结果/位置；返回不自动切回旧空间 |
| RL14 | 390px、键盘、长引用、错误恢复 | 页面无横向溢出，查询/返回可达，错误可读，原行焦点恢复 |
| RL15 | POST/DELETE/tail/export/任意原生表达式、尝试启动采集 | 拒绝；无业务表、执行、模型、Agent或Outbox写入 |
| RL16 | 原新版Agent/业务签收、管理目录/角色/审计和基础配置 | 原接口、严格字段和已有51项/21步路线保持；旧结果不当新HEAD证据 |
