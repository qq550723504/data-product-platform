# 认证、发布、交付与验收归档演示验收

范围：隔离预览 4189，Edge 当前企业经营数据演示空间，延续 REQ-0001 / VER-0002。全部业务操作为标签页合成状态；没有调用模型、外部执行引擎或真实交付。Agent 既有 API 保留。本记录仅声明实际走过的分支。

## 实际浏览器步骤

1. **认证阻断与通过 PASS**：QA-0002 已通过，权利、合规、合约缺失时生成 CERT-0001 未通过。补齐 VER-0002 与必要输入 VER-0001 的权利记录，以及成果合规、合约记录后，新增 CERT-0002 已认证。CERT-0001 历史保留。
2. **发布 PASS**：发布页面逐项展示生产、质量、权利、合规、合约、证据、认证和提供方式。模拟发布 REL-0001，绑定 VER-0002 / CERT-0002；同版本重复发布按钮禁用。
3. **申请与审批 PASS**：GET-0001 初始待审批；直接交付生成 DEL-0001 已阻断，明确缺少批准。我的工作独立批准后返回同一版本和申请。
4. **交付失败与成功 PASS**：模拟调用失败产生 DEL-0002；后续成功产生独立 DEL-0003，旧阻断/失败均保留。成功仅为授权已提交，初始传输未确认；单独追加 TX-0001 模拟传输完成，不混同授权与传输事实。不输出真实链接、凭据或数据。
5. **验收退回与归档 PASS**：分派 → 受理 → 提交已发布 VER-0002 → 退回修改 → 重新提交 → 验收通过 → 归档。WORK-0001 至 WORK-0007 分别保留，已归档后仅有追溯入口；刷新仍保留归档和原办理历史。
6. **撤销后新交付阻断 PASS**：撤销 CERT-0002 后，其认证时结论仍为已认证、当前有效性为已撤销。新 DEL-0004 明确因发布绑定认证失效、当前认证缺失而阻断，旧 DEL-0003 / TX-0001 不被改写。
