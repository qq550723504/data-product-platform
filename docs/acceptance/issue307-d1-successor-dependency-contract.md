# #307 D1 后继依赖与维护保全快照拆分

## 目标和权威边界

本契约只修复后继非删除准备的依赖接纳。原 `issue307-d1-resource-retirement-contract.md`、原清理结果、固定计划和回执继续拥有维护期间保全事实；本契约不回写它们，也不授予任何启动、清理、保护写入、业务删除、发布或合并权限。

根因是同一个 `present_contract()` 同时承担维护期间“整机前后未受影响”证明和后继运行门禁。PID、StartedAt、FinishedAt 是当时观察，不是未来依赖身份。其他会话在维护结束后合法停启，不应令历史退役事实失效。

复用既有 `retired_resources` 的不可变证据、完整CID/descriptor、Docker bytes wrapper和逐项回执，`retired_volumes` 的卷证明，`retired_budget_bytes` 的当前物理预算读取，以及 `evidence_indexes` 的严格路径/哈希工具。无新增运行时、队列、策略引擎或通用清理框架。

## 三个独立结论

1. **维护保全快照**：原入口仍按原计划比较维护期间完整状态，包含其他会话。显式命名为 `verify_maintenance_snapshot()`，仅用于复核原维护范围；不作为后继 `historical_gate()` 的隐式前置。
2. **不可变退役事实**：固定容器/卷/当前PG归档索引、实际执行源码及原失败/预算/pins/54,310原件继续核验。986个容器、106个卷必须具有精确回执，缺失/UNKNOWN不能猜作已退役；36份PG归档必须保持。此阶段不把原 State 投影成当前 State。
3. **后继当前依赖**：独立的 `COLD_PREPARATION` 契约，根据已钉住的退役计划和清理后完整inspect，确定真正源服务与保留数据的当前依赖。成功必须重新读取现场，不能只读缓存结论。

## 后继当前依赖的有限集合

- 显式绑定三组源 Core、Native 共六个完整CID和原业务Redis一个CID。六个源身份来自原冻结candidate22 packet，Redis使用既有维护计划中的原业务服务身份；不是从名称猜测或由调用者传空集合。
- 所有未获退役回执的原保留卷继续存在且元数据完全一致，含58个旧预算。完整现场挂载CID集合必须等于原挂载集合减去已确认退役CID，不能省略范围外使用者、添加新挂载、退款或归零。
- 源服务与上述保留卷的实际保管owner为必要节点；递归加入其 `container:<netns-owner>` 前向父节点。完整CID、Image/Config/HostConfig/Mounts descriptor继续精确绑定。当前必须关闭、PID0、无端口/重启/AutoRemove；不比较历史PID/StartedAt/FinishedAt/ExitCode。不同关闭轮次仍保持旧失败事实不变。
- 不把其他会话加入此集合；不扫描全机无关netns的正确性。不相关会话正常停启、重建或新建不影响此结论，但它们一旦挂载保留卷，完整挂载图检查必须拒绝。当前候选自身隔离和发送证明继续由既有候选拓扑/门禁负责，不能用本历史接纳代替。
- 旧预算原始tar、归属标签、Driver/Options、挂载集合和当前实际物理文件树都核对。空预算、已用/UNKNOWN预算同样严格；任何读取/类型错误均阻断。
- 已退役容器及卷必须在成功的当前完整清单中缺失。Docker错误不表示不存在。原维护计划、回执、授权或冻结候选不更新。

必要集合从固定输入确定并计算稳定hash。后继 `historical_gate()` 只返回新的稳定身份/计数/依赖hash，不返回当前PID等临时观察；旧C22/C23 allocation不能满足新契约，不能自动fallback或续用旧execution。这里不创建新的业务候选或预算。

固定清理后inspect使用原文件的CID映射格式（SHA256 `06e7d4f6790cb673842b8f61b9c9b48d2d11678f7a86d49e1d2ca03788d3431c`）。真实推导为184个必要owner、134个保留卷和7个源角色，其中包括17个在原live/external/additional子集之外、但确实保管保留卷的reader；其完整descriptor由同一固定inspect绑定，不能省略。实际执行源码另核旧两份binding、14个归档源码及原前置回执，不能拿当前新源码替代旧执行字节。

## 验收与收敛

必需成功组合：原维护快照按旧规则通过；后继入口在无关会话正常停启、出现新无关会话、必要服务关闭轮次改变时通过；预算和旧失败保持。

必需拒绝组合：必要源/保管owner/netns父缺失或运行、descriptor/挂载/权限变化；保留卷缺失/归属变化；预算完整挂载扩张、文件改变/重置、原tar变化；已退役CID/卷重现、缺失精确回执、Docker/WSL错误或bytes/str类型错误。完整后继入口必须组合历史事实、现场依赖和物理预算检查，不能只测各模块。

当前阻断限于上述必需路径及保全/历史一致性不变量。额外清理、VHD压缩、通用性能平台、保护延期、原生17版本业务核验、真实删除、新候选/窗口/调度均不在本轮范围。#332保持Draft/unmerged，#307保持OPEN。
